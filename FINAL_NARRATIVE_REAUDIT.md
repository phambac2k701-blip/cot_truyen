## Fixture convention and authority

Each fixture starts from an isolated state. `CASE.A/B/C=2` means authenticated police custody; `X` means verified coordination; `C4` means full D pair plus matched annex preserved before lock. `BARC` derives only from actual received reports. `DECISIVE_LOSS` records the first irreversible closure of a last feasible required path. A terminal fixture advances to an actual closure/explicit end after processing due receipts; an open saving path stays playable. Times are the authored `OBJECTIVE_TIME`, never elapsed reading time. Expected transitions are predictions; “Actual document result” names the independently checked rule and observed documentary disposition, not a runtime execution.

For compactness, file names in the fixtures use: **BT** = `BACKSTAGE_CRIME_TRUTH.md`, **CW** = `CHARACTER_WEB.md`, **OT** = `OBJECTIVE_TIMELINE.md`, **CG** = `CLUE_GRAPH.md`, **EL** = `ENDING_LOGIC.md`, **PS** = `PLAYER_STORY.md`, **SB** = `SCENE_BREAKDOWN.md`, **FS** = `FULL_SCRIPT.md`, **ES** = `EVENT_IMPLEMENTATION_SPEC.md`, **AM** = `SCENE_ASSET_MANIFEST.md`.
